# Ghardaïa en famille

Application du séjour dans la vallée du M'Zab, du 25 au 27 octobre 2026. Installable sur l'écran d'accueil et utilisable hors ligne.

## Rubriques
- **Dim. 25, Lun. 26, Mar. 27** : programme dans l'ordre fixé avec le guide. Pour chaque étape : commentaire de guide documenté, version enfants, ce qu'il faut voir, question à poser au guide, défi enfants. Tout est lisible à voix haute.
- **Guide** : Comprendre le M'Zab, Les incontournables, Balades à pied (Ghardaïa, Béni Isguen), Comprendre (histoire, Mozabites, schémas du ksar, de la maison et de l'eau), Carte, Que manger, Qu'acheter, Savoir-vivre, Le ciel des dunes, Infos pratiques, Adresses de l'hôte, Pour aller plus loin, Sources.
- **Photos** : photos libres de Wikimedia Commons avec crédits, visibles dans l'application installée.
- **Prières** : horaires calculés pour Ghardaïa (aube 18°, nuit 17°, Asr standard), prochaine prière dans le bandeau.
- **Enfants** : bingo du M'Zab et quiz du soir.
- **Pratique** : sac du jour, mots de darija à écouter.

Le bandeau du haut affiche l'heure de Ghardaïa, l'étape en cours, le compte à rebours de la belle lumière avant le coucher du soleil et la prochaine prière.

## Installer sur le téléphone
1. Activer GitHub Pages : Settings → Pages → Deploy from a branch → `main` / `(root)`.
2. Ouvrir le site une première fois avec du réseau.
3. iPhone : Partager → « Sur l'écran d'accueil ». Android : menu → « Installer l'application ».

Les faits ont été vérifiés auprès des sources listées dans la rubrique « Sources ».

## Voix
Les commentaires sont enregistrés dans `audio/` avec la voix française neuronale « Siwis » (moteur Piper, données Siwis sous licence CC BY 4.0, université d'Édimbourg). Si un fichier manque, l'application utilise la voix du téléphone. Réglage de la voix et de la vitesse dans l'onglet Pratique.
